# Tamify

> Tamify Desktop Edition — Windows packaging is being prepared.

Tamify is an intelligent Tamil legacy document OCR, PDF-to-Excel (`.xlsx`), BAMINI/TSCII/TAB converter, and Keezhadi Typewriter & Unicode DOCX studio.

## Desktop Edition (Windows 10/11)

Tamify is packaged as a standalone Windows desktop application using Electron and Electron Forge.

### Development Commands

```bash
# Web browser development
npm run dev

# Compile all production bundles (Frontend, Express backend, Electron)
npm run build

# Run Electron desktop application locally
npm run electron:dev

# Build Windows installer (Tamify-Setup.exe)
npm run make:windows
```
